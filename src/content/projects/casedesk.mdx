## Summary

Lawyers start their day on one screen: what is overdue, and what is coming up this week. CaseDesk rebuilds that Today page. Overdue tasks sit in a Top priority list, followed by the next seven days of tasks and calendar events grouped by day.

The work went into the parts a real product needs: keeping each firm's data separate, getting "today" right in every firm's time zone, and keeping the page fast when a user has tens of thousands of tasks.

## Highlights

- Multi-tenant by design. Every lookup goes through the signed-in user (`Current.user.assigned_tasks.find`), so one firm can never load another firm's data.
- Per-firm time zones decide what counts as "today" and "overdue", and how days are grouped.
- Mark complete without a reload: a Turbo Stream removes the card and shows "Nothing overdue" when the last one is gone.
- Tests for models, controllers and helpers run on GitHub Actions with RuboCop and Brakeman.

## Performance

Benchmarked with 1M tasks and 200K calendar events. The busiest user has about 70K tasks, most of them completed.
